# HOPPER-G

> **Status:** research in progress (follow-up to [HOPPER](https://github.com/sungchul02/HOPPER)). Details and code will be released with the paper.

HOPPER-G is ongoing research on context compression for small language models that uses the connections between documents. The method, results and code will be added when the paper is published.

---

HOPPER-G는 문서 사이의 연결을 이용해 소형 언어모델의 입력 문맥을 압축하는 연구로, 현재 진행 중이다. [HOPPER](https://github.com/sungchul02/HOPPER)의 후속 연구이며, 방법, 결과, 코드는 논문 공개 시 이 저장소에 기재한다.
